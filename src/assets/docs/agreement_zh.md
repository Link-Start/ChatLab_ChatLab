欢迎使用 ChatLab，它是一款**开源、本地化的聊天记录分析工具**。

我们相信，你有权理解自己的社交数据。但聊天记录不只属于你，它同时承载着你朋友、家人、同事的话语与信任。因此，在使用本工具之前，请认真阅读以下条款。

## 1. 核心功能与独立性

- **仅分析，不导出**：本工具仅用于对已导出的聊天记录进行分析。我们不提供任何解密、抓包或导出工具，从第三方聊天软件获取数据是你的个人行为。
- **第三方独立工具**：本项目为独立开源项目，**与任何聊天平台、公司或组织无关联**。

## 2. 数据隐私与安全

- **本地分析**：默认情况下，聊天记录的存储与分析均在你的设备本地完成，**零上传**。应用可能联网获取更新、说明和配置信息，但不会因此上传本地数据。
- **外部功能例外**：使用 AI 时，相关聊天数据会发送至你配置的模型服务商，其隐私政策独立于 ChatLab；启用 API、MCP 或对外部署后，连接的客户端可能访问 ChatLab 数据。请自行评估风险并妥善保管凭证。
- **匿名使用统计**：为改进产品，软件会发送匿名标识、运行环境和功能使用情况，但不会收集聊天内容、联系人等聊天数据。你可以在设置中随时关闭此功能。

## 3. 数据授权与合规责任

聊天记录中不只有你的数据——它同样包含对话另一方的内容。请在使用时遵守以下原则：

- **合法授权原则**：你仅可处理你**本人参与**的聊天记录。聊天记录中涉及的其他参与者同样拥有隐私权，若分析内容涉及特定个人隐私（**私聊对象、群聊成员**），请务必确保已获得相关人员的知情同意。
- **合法使用责任**：你应遵守所在地适用法律，不得利用本软件实施窃取、监控、诈骗、骚扰、人肉搜索等违法或侵权行为，也不得处理通过非法入侵、账号窃取或数据劫持等方式获得的聊天记录。对于软件及 AI 生成的内容，请勿将其用于编造或传播虚假、误导性信息。

## 4. 风险警告

- **官方渠道**：请仅通过 [chatlab.fun](https://chatlab.fun) 或 [GitHub Releases](https://github.com/ChatLab/ChatLab/releases) 下载软件。非官方版本可能包含恶意代码，导致 API Token、聊天记录或本地数据泄露。
